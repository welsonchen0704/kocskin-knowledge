## 2. 技術踩雷（四項，踩過才記下來的）

1. **寫入時用 literal 中文，不要用 `\uXXXX` escape。**
   escape 會導致部分字元被寫錯。實際發生過：防曬「霜」→「霓」、蜂「蠟」→簡體「蜡」。

2. **SQL 查詢時「貼」字容易被轉寫成「貪」而報錯。** 遇到就改查其他欄位，或用欄位順序／其他條件繞過。

3. **寫入後必須讀回全文比對（憲章 R7 驗證不自驗）。** 特別檢查商品名稱與繁簡體。

4. **寫入前先查既有排程避免撞期：**

   ```sql
   SELECT "date:發文日期:start", "發文平台", "發文狀態"
   FROM "collection://04b770fc-b2fa-4185-85e4-b6245777557d"
   WHERE "發文平台"='Threads' ORDER BY 1 DESC
   ```

## 3. 選圖邏輯（半自動：系統挑候選，人選一張）

**素材圖庫索引：** `collection://a924b6bd-c492-4328-93ea-3d036229301f`

欄位：圖名／SKU／商品(relation)／商品名／場景／類型／狀態／圖片網址／尺寸／備註

### 為什麼是半自動

規則挑得出正確 SKU，挑不出「這張圖看起來像不像真人隨手拍」——而那正是 Threads 圖片唯一的判準（R-1）。所以：**系統挑 2–3 張候選，附上圖名與類型，由人選一張。**

### 候選查詢

```sql
SELECT "圖名", "SKU", "類型", "場景", "圖片網址"
FROM "collection://a924b6bd-c492-4328-93ea-3d036229301f"
WHERE "SKU"='KOCxxx' AND "狀態"='可用'
```

### Threads 的類型優先序

| 優先 | 類型 | 說明 |
|---|---|---|
| 1 | **實拍** | 最符合 R-1，優先中的優先 |
| 2 | AI實景 | 可用，但要挑不像商業攝影的 |
| ❌ | 白底 | 商品目錄照，太像廣告 |
| ❌ | 設計卡 | 直接違反 R-1，永不採用 |

**若該 SKU 沒有「實拍」**：明講「此 SKU 目前只有 AI實景／白底，Threads 建議走純文字」，不要硬塞白底圖。

> 目前 45 個在售 SKU 中只有 26 個有實拍，**19 個缺**（含三個高單價利潤引擎：KOC061 玫瑰超導全能安瓶、KOC067 玫瑰超導全能乳液、KOC068 H7抗老緊緻精華加大版）。這是拍攝缺口，不是技術問題。

### 去重

素材庫**沒有「最近使用」欄位**。避免重複用同一張的做法：查社群貼文 DB 近期已用的圖片網址，從候選中排除。

```sql
SELECT "圖片網址" FROM "collection://04b770fc-b2fa-4185-85e4-b6245777557d"
WHERE "發文平台"='Threads' ORDER BY "date:發文日期:start" DESC
```

## 4. Cloudinary 尺寸切換

**Cloud name：** `s55rhpbr`
**基本網址：** `https://res.cloudinary.com/s55rhpbr/image/upload/{public_id}.jpg`

一張原圖可以動態衍生所有比例——在 `upload/` 後面插參數即可，不必重複上傳。

| 平台 | 參數 | 說明 |
|---|---|---|
| **Threads** | `c_limit,w_1080` | **只限寬、不裁切**。裁切會讓圖看起來被處理過，違反「隨手拍」感 |
| FB 連結圖 | `c_fill,g_auto,w_1200,h_630` | （FB/IG 走 `kocskin-post-writer`，此處僅供對照） |
| IG 方形 | `c_fill,g_auto,w_1080,h_1080` | 同上 |
| IG 直式 | `c_fill,g_auto,w_1080,h_1350` | 同上 |

範例：

```
https://res.cloudinary.com/s55rhpbr/image/upload/c_limit,w_1080/koc_real_01.jpg
```

### 上傳（需要新圖時）

工具 `mcp__Cloudinary__upload-asset`：

- **可靠上傳法**：`file` 帶「公開 HTTPS 網址」→ Cloudinary 抓圖入庫，任何大小都穩。
- ⚠️ 大圖（數十 KB 以上）**不要**用 inline base64，會 `Could not decode base64`。小圖才可用 data URI。
- 回傳 `secure_url`，填進 Notion 貼文列的「圖片網址」。
