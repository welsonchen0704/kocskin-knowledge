# KOCSKIN 合規審查

KOCSKIN 任何對外文案在發布前的**最後一道守門**。目的：在違規文字觸及消費者之前攔下。

本 skill 是憲章 R2「四關逐關結論」的**唯一正本**。其他 skill（threads-writer、post-writer、ad-wireframe、visual-generator）引用四關時一律指向本檔〈四關審查格式〉，不得自存另一版。

## 核心檢查清單（6 大類，抓問題用）

審查時依序掃描文案，依嚴重度分級並給出替代建議。

### 🔴 Critical（發布會有法律風險，必改）

1. **化粧品違規宣稱**：宣稱醫療效能、療效、藥效，例如「治療」「預防」「改善皺紋」「消除」「去除」「淡化」「殺菌」「抗發炎」「取代醫美」
2. **保健食品違規宣稱**：宣稱治療或預防疾病，例如「降血壓」「治糖尿病」「抗癌」「取代藥物」
3. **虛偽誇大或無證據保證**：「100% 有效」「零副作用」「立即見效」「百分百保證」
4. **違反個人資料保護**：揭露消費者個資、醫療狀況

### 🟠 High（違反 KOCSKIN 品牌紅線，必改）

5. **提及停售商品／未販售紅線品**：
   - 名單唯一正本＝[references/brand-rules.md](references/brand-rules.md)〈一、停售商品〉（含未販售紅線品、2026-07-13／07-14 停售批次、KOCS001 暫停販售特例）；機器判定用 Notion V2 `SKU狀態` 即時值
   - ⚠️ 勿誤判相似名【在售品】：「KOC 益生守護者益生菌」「KOCSKIN 晶燦白皙氣墊粉餅」為正常在售商品，可正常提及，不要誤攔（防混淆規則詳見正本）
6. **錯誤歸類商品**：
   - 玫瑰超導全能安瓶 → **不得**歸入 PDRN 線（實際是山茶花外泌體，Welson 2026.04.13 確認）
7. **使用執行長本名**：一律用「小燕」或「執行長小燕」，不得使用「李燕」
8. **真實名人虛構引述**、**代真人陳述未經本人確認**（小燕第一人稱經歷、「客服同事說」等幕後型陳述）——正本見 brand-rules〈三〉與 threads-rules 第 6 節

### 🟡 Medium（品牌語氣偏離，建議改）

9. **焦慮行銷**：過度恐嚇（「再不用 XX 你就會…」「皮膚已經壞光光」）與品牌定位「親切、專業、有溫度」不符
10. **過度誇大**：「神級保養」「奇蹟」「逆天」與品牌「不誇大」原則相違
11. **簡體字混入**：檢查有沒有「护」「发」「产」「为」「后」等簡體字（品牌全域紅線，機器產出過 opencc；發現即列 Medium 並直接給繁體修正）

### 🟢 Low（可優化，不強制）

12. **英文縮寫未解釋**：例如只寫 PDRN / SWT-7 / HA 未附中文說明
13. **hashtag / CTA 缺漏**：FB / IG 貼文建議檢查
14. **格式問題**：重複斷行、標點誤用（全形/半形混用）

## 美白宣稱規則（Welson 2026-08-05／08-08 更正；本節優先於 references/compliance-rules.md〈一〉美白列，也推翻 product-lookup schema.md 裁定摘要 #1 與 2026-07-11「傳明酸可訴求美白」的舊裁定）

- 「美白」屬特定用途化粧品宣稱，**須該產品本身取得特定用途化粧品許可證（衛部粧製字第◯◯◯號）**方可使用。許可證是**產品層級**，不隨成分、不隨產品線延伸。
- **含核可成分（傳明酸、熊果素…）≠ 取得宣稱資格。**「成分在核准名單」「同系列有證」「已備查」都不足以放行——一般化粧品備查 ≠ 特定用途許可。
- 無許可證者：成分可如實列示，但不得連結美白效果，只能用「亮白／提亮／透亮／淨透／膚色均勻」。
- **同時禁用**「衛福部核准／核可美白成分」「核准美白關鍵成分」等表述——暗示特定用途許可，風險高於單寫「美白」。
- 「不反黑」＝美白脈絡專有詞，改用「不具光敏感」；「高濃度」無客觀基準，直接寫數字。
- 目前極光美白系列三品、KOC050、香氛美白保濕體乳等皆**無**美白文號（以 V2 合規卡即時值為準，若日後取得許可證由 Welson 更新卡片）。

**整體表現原則（2026-08-08 新增）**：化粧品廣告採整體表現與總體印象認定，非逐字比對。移除「美白」二字但保留「核可成分 → 不反黑 → 透亮 → 膚色均勻」敘事鏈，仍是美白訴求，列 🟠 High。判定法：把整段當一句話讀，問「消費者會認為這在賣什麼效果？」破解法：成分只出現在成分欄，訴求句不做成分→效果的因果連結。

**誤判白名單（勿攔）**：「胜肽」是台灣正體標準用字，不是簡體；「修復／修護」合法（僅「修復傷口」不合法）；小燕完整簽名句見 brand-rules〈九〉。

## 執行流程

### Step 1：先確認文案上下文

問使用者（或從對話判斷）：
- 這段文案是發布到哪個渠道？（FB / IG / Threads / LP / 廣告 / LINE / Email / 客服）
- 主推的商品是哪支？（有的話順便用 `kocskin-product-lookup` 查商品資料和「合規備注」「禁用說法」「合規可用說法」欄位，作為審查依據）

若使用者沒說，先掃一次文案猜主推商品，若有明確商品名稱就自動查 DB 的合規備注。

### Step 2：掃描文案

依〈核心檢查清單〉掃描，**每條違規都要列出**（不要只報告第一個）：
- 原文引用（違規詞句）
- 歸類（Critical / High / Medium / Low）
- 違反的規則編號和法規依據
- 建議替代說法（可多個版本）

完整禁用詞 / 替代詞清單見：
- [references/compliance-rules.md](references/compliance-rules.md)（化粧品 / 保健食品法規）
- [references/brand-rules.md](references/brand-rules.md)（KOCSKIN 品牌紅線）
- [references/replacements.md](references/replacements.md)（違規詞 → 合規替代字典）

### Step 3：輸出格式（兩段式：四關結論 ＋ 逐條問題）

**第一段：四關審查格式（憲章 R2 要求的「逐關結論」，每次必出、不得省略）**

```
⚖️ 合規審查結果｜[渠道]｜[主推商品或「無主角商品」]

第一關｜醫療效能 —— 是否宣稱治療、預防疾病、改善症狀？
  → ✅ 通過 ／ ⚠️ 需確認或微調 ／ 🔴 需修正才可發｜[一句理由，或列出觸發詞]
第二關｜改變身體結構 —— 是否宣稱瘦身、豐胸、除皺、消除皺紋？
  → ✅／⚠️／🔴｜[理由]
第三關｜特定用途無文號 —— 美白／防曬等是否有「該產品本身」的特定用途化粧品許可證（衛部粧製字第◯◯◯號）？（查 V2 合規卡；見〈美白宣稱規則〉——含核可成分 ≠ 有宣稱資格，目前無許可證的 SKU 一律只能「亮白／透亮／淨透」）
  → ✅／⚠️／🔴｜[理由]
第四關｜整體是否誤導 —— 症狀圖、前後對比、無佐證的「臨床證實／獲獎／專利」、絕對性保證？
  → ✅／⚠️／🔴｜[理由]
品牌紅線 —— 簡體字、停售品、絕對禁語（第一／最／唯一／保證…）、真實名人虛構引述、執行長稱謂、PDRN 線歸類、幕後型／代真人陳述是否已確認？
  → ✅／⚠️／🔴｜[理由]

總體判定：🔴 不可發布 ／ 🟠 需修改 ／ 🟡 建議調整 ／ 🟢 通過
發現 X 個問題（Critical N / High N / Medium N / Low N）
```

判定規則：任一關 🔴 → 總體 🔴 不可發布；任一關 ⚠️ 且無 🔴 → 🟠 或 🟡（依嚴重度）；五關全 ✅ → 🟢。「品牌簽名句白名單」（brand-rules〈九〉）完整片語不觸發品牌紅線。

**第二段：逐條列出問題**（有問題才出；全 ✅ 時可省）

```
---
🔴 Critical #1｜化粧品違規宣稱（對應第一關）
📌 原文：「[違規原句]」
❌ 問題：宣稱醫療效能「消除皺紋」違反《化粧品衛生安全管理法》第 10 條
✅ 建議改為：
   - 版本 A：「撫平細紋外觀」
   - 版本 B：「幫助肌膚看起來更緊緻」
---
```

**最後給修改版全文**：若問題不多（< 5 個），直接產出修改後的完整版文案方便使用者複製。若問題多到建議整段重寫，明說「建議重寫」並提供重寫方向。

### Step 4：主動補充

- 若偵測到**主推商品有 `合規備注`／`禁用說法` 欄位內容**，主動把該備注內容帶給使用者看（常常已經寫好對該商品的禁用與建議用詞）
- 若是**保健食品**，額外提醒：不能暗示替代藥物、不能對症狀做療效承諾；KOC047 益生菌避用「幫助維持消化道機能」等生理機能句（無健康食品字號，見 V2 合規卡）
- 若是**廣告素材**，提醒要保留修改紀錄（Meta 審查可能抽查）；素材中若有小燕入鏡，整張素材不得有任何功效字句（ad-wireframe 第四節）
- 若是 **Threads**，額外查「症狀描述 → 商品」結構（暗示改善症狀＝違規）

## 獨立審查的執行方式（憲章 R2）

產出與審查必須由不同的一方做。

- **Claude Code／Cowork**：由 fresh subagent 執行本 skill，只審不改，回傳上述四關格式。
- **claude.ai 對話**：產出後下一輪只審不改。
- 審查通過的證據是**逐關結論**，不是一句「已檢查」。Critical／High 修正後必須**再審一次**。

## 使用情境

這個 skill 一定要在下列情境觸發：

1. 使用者貼一段文案問「這樣寫 ok 嗎」「有沒有問題」「會違法嗎」
2. 使用者說「要上稿了」「要發布了」「要投廣告了」—— 主動提議跑一次合規審查
3. **其他 skill 產出文案後**（`kocskin-post-writer`、`kocskin-threads-writer`、`kocskin-ad-wireframe`、`kocskin-visual-generator` 的圖面文字）應該自動接上 compliance-check 當最後一道
4. 使用者想檢視既有上架文案有沒有歷史違規（例如舊 LP 定期審）

## 不要做的事

- ❌ 不要自己產創意文案（這是 kocskin-post-writer／kocskin-threads-writer 的工作；本 skill 只審查不創作）
- ❌ 不要「放行」有 Critical 問題的文案，即使使用者說「這樣就好」也要堅持攔下（可以用不同替代方案給他選，但不要假裝它合規）
- ❌ 不要只給逐條問題清單而省略四關結論——R2 要的是逐關結論
- ❌ 不要用簡體字回應
- ❌ 不要憑一般知識判斷，優先以 [references/compliance-rules.md](references/compliance-rules.md) 的台灣法規為準（美國 / 中國 / 香港標準不適用）
- ❌ 不要誤判「修復」「修護」為違規詞——這兩個在化妝品是合法用字
- ❌ 不要攔小燕完整簽名句片語「最實惠的價格」「最有效的保養品」——品牌白名單豁免（Welson 2026-08-02 裁定），僅限完整片語，拆開單用仍攔；見 [references/brand-rules.md](references/brand-rules.md)〈九、品牌簽名句白名單〉
- ⚠️ 邊界案例（不確定合不合規）要標註「建議法務覆核」而非硬說沒問題
- ⚠️ 法規最後核對日 2026-08-08（美白規則更正時）；2027-02 起未重核前，審查結論加註「法規核對日已逾 6 個月，建議 Welson 重核」。帳號版 references/compliance-rules.md 仍是 2026-04 快照（缺 8/8 更正），以本檔〈美白宣稱規則〉為準，直到 Welson 重新上傳 reference

## 為什麼這個 skill 重要

Welson CLAUDE.md 明訂「所有對外內容需符合台灣化粧品與保健食品廣告法規」，但這些規則分散在：
- 衛福部法規條文
- 實際 Notion 商品 DB 的合規備注欄位
- 停售商品、PDRN 線歸類等內部備忘

這個 skill 把三者合一，讓任何對話（你、團隊、其他 skill）都能共用同一套守門邏輯，不依賴誰的記憶。違規成本（衛福部罰鍰 60 萬起跳、Meta 廣告被封、商品下架）遠高於 skill 建置成本。
