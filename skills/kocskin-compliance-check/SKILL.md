# KOCSKIN 合規審查

KOCSKIN 任何對外文案在發布前的**最後一道守門**。目的：在違規文字觸及消費者之前攔下。

## 核心檢查清單（6 大類）

審查時依序掃描文案，依嚴重度分級並給出替代建議。

### 🔴 Critical（發布會有法律風險，必改）

1. **化粧品違規宣稱**：宣稱醫療效能、療效、藥效，例如「治療」「預防」「改善皺紋」「消除」「去除」「淡化」「殺菌」「抗發炎」「取代醫美」
2. **保健食品違規宣稱**：宣稱治療或預防疾病，例如「降血壓」「治糖尿病」「抗癌」「取代藥物」
3. **虛偽誇大或無證據保證**：「100% 有效」「零副作用」「立即見效」「百分百保證」
4. **違反個人資料保護**：揭露消費者個資、醫療狀況

### 🟠 High（違反 KOCSKIN 品牌紅線，必改）

5. **提及停售商品／未販售紅線品**：
   - 名單唯一正本＝[references/brand-rules.md](references/brand-rules.md)〈一、停售商品〉（含未販售紅線品、2026-07-13／07-14 停售批次、KOCS001 暫停販售特例）；機器判定用 Notion V2 `SKU狀態` 即時值
   - ⚠️ 勿誤判相似名【在售品】：「KOC 益生守護者益生菌」「KOCSKIN 晶燦白皙氣墊粉餅」為正常在售商品，可正常提及，不要誤攔（防混淆規則詳見正本）
6. **錯誤歸類商品**：
   - 玫瑰超導全能安瓶 → **不得**歸入 PDRN 線（實際是山茶花外泌體，Welson 2026.04.13 確認）
7. **使用執行長本名**：一律用「小燕」或「執行長小燕」，不得使用「李燕」

### 🟡 Medium（品牌語氣偏離，建議改）

8. **焦慮行銷**：過度恐嚇（「再不用 XX 你就會…」「皮膚已經壞光光」）與品牌定位「親切、專業、有溫度」不符
9. **過度誇大**：「神級保養」「奇蹟」「逆天」與品牌「不誇大」原則相違
10. **簡體字混入**：檢查有沒有「护」「发」「产」「为」「后」等簡體字

### 🟢 Low（可優化，不強制）

11. **英文縮寫未解釋**：例如只寫 PDRN / SWT-7 / HA 未附中文說明
12. **hashtag / CTA 缺漏**：FB / IG 貼文建議檢查
13. **格式問題**：重複斷行、標點誤用（全形/半形混用）

## 執行流程

### Step 1：先確認文案上下文

問使用者（或從對話判斷）：
- 這段文案是發布到哪個渠道？（FB / IG / LP / 廣告 / LINE / Email / 客服）
- 主推的商品是哪支？（有的話順便用 `kocskin-product-lookup` 查商品資料和「合規備注」欄位，作為審查依據）

若使用者沒說，先掃一次文案猜主推商品，若有明確商品名稱就自動查 DB 的合規備注。

### Step 2：掃描文案

依〈核心檢查清單〉掃描，**每條違規都要列出**（不要只報告第一個）：
- 原文引用（違規詞句）
- 歸類（Critical / High / Medium / Low）
- 違反的規則編號和法規依據
- 建議替代說法（可多個版本）

完整禁用詞 / 替代詞清單見：
- [references/compliance-rules.md](references/compliance-rules.md)（化粧品 / 保健食品法規）
- [references/brand-rules.md](references/brand-rules.md)（KOCSKIN 品牌紅線）
- [references/replacements.md](references/replacements.md)（違規詞 → 合規替代字典）

### Step 3：輸出格式

**總結開頭**：
```
⚖️ 合規審查結果｜[文案用途 / 主推商品]

總體評級：🔴 不可發布 / 🟠 需修改 / 🟡 建議調整 / 🟢 通過
發現 X 個問題（Critical N / High N / Medium N / Low N）
```

**逐條列出**：
```
---
🔴 Critical #1｜化粧品違規宣稱
📌 原文：「[違規原句]」
❌ 問題：宣稱醫療效能「消除皺紋」違反《化粧品衛生安全管理法》第 10 條
✅ 建議改為：
   - 版本 A：「撫平細紋外觀」
   - 版本 B：「幫助肌膚看起來更緊緻」
---
```

**最後給修改版全文**：若問題不多（< 5 個），直接產出修改後的完整版文案方便使用者複製。若問題多到建議整段重寫，明說「建議重寫」並提供重寫方向。

### Step 4：主動補充

- 若偵測到**主推商品有 `合規備注` 欄位內容**，主動把該備注內容帶給使用者看（常常已經寫好對該商品的禁用與建議用詞）
- 若是**保健食品**，額外提醒：不能暗示替代藥物、不能對症狀做療效承諾
- 若是**廣告素材**，提醒要保留修改紀錄（Meta 審查可能抽查）

## 使用情境

這個 skill 一定要在下列情境觸發：

1. 使用者貼一段文案問「這樣寫 ok 嗎」「有沒有問題」「會違法嗎」
2. 使用者說「要上稿了」「要發布了」「要投廣告了」—— 主動提議跑一次合規審查
3. **其他 skill 產出文案後**（`marketing:draft-content`、`marketing:content-creation`、`kocskin-post-writer`、`kocskin-threads-writer`）應該自動接上 compliance-check 當最後一道
4. 使用者想檢視既有上架文案有沒有歷史違規（例如舊 LP 定期審）

## 不要做的事

- ❌ 不要自己產創意文案（這是 marketing 系列 skill 的工作；本 skill 只審查不創作）
- ❌ 不要「放行」有 Critical 問題的文案，即使使用者說「這樣就好」也要堅持攔下（可以用不同替代方案給他選，但不要假裝它合規）
- ❌ 不要用簡體字回應
- ❌ 不要憑一般知識判斷，優先以 [references/compliance-rules.md](references/compliance-rules.md) 的台灣法規為準（美國 / 中國 / 香港標準不適用）
- ❌ 不要誤判「修復」「修護」為違規詞——這兩個在化妝品是合法用字
- ❌ 不要攔小燕完整簽名句片語「最實惠的價格」「最有效的保養品」——品牌白名單豁免（Welson 2026-08-02 裁定），僅限完整片語，拆開單用仍攔；見 [references/brand-rules.md](references/brand-rules.md)〈九、品牌簽名句白名單〉
- ⚠️ 邊界案例（不確定合不合規）要標註「建議法務覆核」而非硬說沒問題

## 為什麼這個 skill 重要

Welson CLAUDE.md 明訂「所有對外內容需符合台灣化粧品與保健食品廣告法規」，但這些規則分散在：
- 衛福部法規條文
- 實際 Notion 商品 DB 的合規備注欄位
- 停售商品、PDRN 線歸類等內部備忘

這個 skill 把三者合一，讓任何對話（你、團隊、其他 skill）都能共用同一套守門邏輯，不依賴誰的記憶。違規成本（衛福部罰鍰 60 萬起跳、Meta 廣告被封、商品下架）遠高於 skill 建置成本。
