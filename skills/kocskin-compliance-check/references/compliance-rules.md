# 台灣化粧品 / 保健食品法規 — 禁用詞與合規替代

本檔基於 2024-2026 年衛福部食藥署（TFDA）公告整理。法規會隨時更新，邊界案例請 Welson 諮詢法務。

---

## 一、化粧品（含保養品、彩妝、洗浴）

### 法規依據

- 《化粧品衛生安全管理法》（2019 修正版）
- 食藥署「化粧品得宣稱詞句例示及不適當宣稱詞句例示」

### 🔴 絕對禁止（涉及醫療效能，違者罰 60-500 萬）

| 禁用類型 | 典型禁用詞 | 為什麼 |
| --- | --- | --- |
| 疾病治療 | 治療、療效、治癒、根治、改善（疾病）、消炎、殺菌、消毒、解毒、抗敏 | 疾病治療屬醫療行為，化粧品非藥物 |
| 消除皺紋 / 細紋 | 消除皺紋、撫平皺紋、淡化皺紋、去除皺紋、除皺、除細紋、撫平細紋（單獨用） | 可用「撫平細紋**外觀**」「看起來更緊緻」 |
| 消除斑點 / 黑色素機轉 | 消除斑點、淡斑、去斑、美白淡斑（對斑宣稱）、治療色斑、調節／抑制／阻斷黑色素、防止色斑形成 | 可用「均勻膚色」「提亮」；「調節黑色素」2026-09-27 起禁用（機轉宣稱），不再作為替代語 |
| 消除痘痘 | 抗痘、消痘、治痘、除痘、淡化痘疤 | 可用「油水平衡」「清爽膚況」「調理肌膚」 |
| 減肥 / 瘦身 | 瘦身、減肥、燃脂、減脂、消脂、緊實塑身（宣稱瘦）、去除橘皮 | 化粧品不得宣稱瘦身 |
| 醫美替代 | 媲美醫美、取代醫美、電波拉皮、小針美容、注射級、拉皮、埋線、微整 | 禁止類比醫療行為 |
| 生理改變 | 豐胸、豐乳、加速新陳代謝（全身性）、調節荷爾蒙、促進生長 | 生理改變屬藥品範圍 |
| 傷口 / 病理 | 修復傷口、癒合、治療傷疤、曬傷修復、醫美術後立即使用、抗發炎、抗過敏 | 屬醫療行為 |
| 預防性宣稱 | 預防皮膚癌、預防光老化（直接宣稱）、防止黑色素生成（過度表述） | 預防疾病屬藥品 |

### 🟠 可用但需謹慎（常被查核，建議搭配效果描述而非承諾）

| 類型 | 可用詞（需謹慎） | 注意 |
| --- | --- | --- |
| 美白（限極光美白三品） | 美白、美白肌膚、亮白、白皙、淨白、嫩白、皙白、均勻膚色、明亮 | 僅 KOC022 極光美白精華／KOC042 極光美白神仙水／KOC030 極光美白乳霜 可用「美白」等詞（2026-09-27 Welson 拍板，正本＝憲章 R3 例外條款）；其餘品項只能用「亮白」「透亮」「提亮」。仍禁：淡斑／淡化斑點／調節、抑制或阻斷黑色素／防止色斑形成等機轉宣稱；「衛福部核准／核可美白成分」等暗示官方核准之表述（現行制度已無核准機制）；KOC030 獲獎／專利／TranEX-1／胜肽。KOC050 不在本次裁定範圍，以 V2 合規卡為準 |
| 抗老（不針對皺紋治療） | 抗老、緊緻、回彈、煥活、抗氧化 | 不要接「消除細紋 / 皺紋」 |
| 保濕 / 修護（肌膚屏障） | 保濕、修護、修復、舒緩、修護肌膚屏障 | 「修護」化粧品合法，「修復傷口」不合法 |
| 防曬 | 需標示 SPF / PA 及數值、要有主管機關核備 | 不得宣稱「防曬傷」（傷屬醫療） |

### 🟢 一律合法（安心使用）

- 清潔、保濕、潤澤、柔嫩、光滑、細緻、緊緻膚觸、明亮、透亮、飽滿
- 撫平肌膚紋理、看起來更年輕、肌膚觸感升級
- 修護肌膚屏障、舒緩乾燥不適、平衡油水

## 二、保健食品（含膠囊、益生菌、機能性食品）

### 法規依據

- 《食品安全衛生管理法》
- 《健康食品管理法》（只有取得健康食品字號才能宣稱特定功效）
- 食藥署「食品之標示宣傳或廣告涉及不實誇張易生誤解或醫療效能之認定基準」

### 🔴 絕對禁止（罰 60 萬起）

| 禁用類型 | 典型禁用詞 | 為什麼 |
| --- | --- | --- |
| 治療疾病 | 治療 X 病、預防癌症、抗癌、治糖尿病、降血壓（宣稱治療）、治療失眠、治便秘 | 保健食品不是藥 |
| 醫療級用詞 | 醫療級、藥用級、醫師推薦（未有資料）、處方等級 | 暗示醫療行為 |
| 疾病名稱 | 高血壓、糖尿病、癌症、憂鬱症、失智症、心血管疾病、骨質疏鬆（宣稱改善） | 不得宣稱針對特定疾病 |
| 生理症狀治療 | 治便秘、治失眠、治胃痛、止痛、退燒 | 症狀治療屬醫療 |
| 絕對性承諾 | 100% 有效、完全根治、永久治癒、立即見效、保證 | 虛偽誇大 |
| 取代藥物 | 取代藥物、停藥也能、不用看醫生 | 危險暗示 |

### 🟠 健康食品字號限定（有字號才能用對應宣稱）

如果 KOC 保健食品取得「健康食品字號」，可依字號核准範圍宣稱，例如：
- 調節血脂、調節免疫力、胃腸功能改善、骨質保健、牙齒保健、延緩衰老、促進鐵吸收、抗疲勞、護肝

**沒有字號一律不得宣稱**。寫作前請 Welson 確認該保健食品有無字號。

### 🟢 一律合法（通用保健表述）

- 補充營養、均衡飲食、提供活力、健康維持、補充 X（維生素/礦物質/益生菌）
- 專為 X 族群設計（忙碌上班族、銀髮族、愛美女性等）
- 源自 X（成分來源，如「挪威深海魚油」「瑞典葉黃素」）
- 日常保養、打造健康生活、養成保健習慣

## 三、廣告通用規則（跨產品）

### 🔴 絕對禁止

1. **假見證 / 假客評**：未經授權或虛構的消費者見證
2. **前後對比誤導**：修圖 / 不同光源 / 不同角度假冒「使用後效果」
3. **醫師 / 藥師 / 護理人員代言醫療宣稱**：除非廣告屬學術範圍且有醫護專業身份揭露
4. **影射他牌**：「比 XX 牌更好」「擊敗 YY 商品」
5. **抽獎 / 贈獎違規**：未標明活動期間、公開抽獎方式、中獎人數

### 🟠 易踩雷

6. **使用「第一」「最」「唯一」「最好」**：除非有第三方公證機構認證數據，否則違反公平交易法
7. **使用「純天然」「100% 天然」**：除非全成分皆天然且可證明
8. **使用「無添加 X」**：需列出具體無添加項目，不得模糊
9. **健康食品免責聲明漏列**：健康食品字號產品要揭露「本產品經衛生福利部認證具 XX 功能……惟仍應遵守……」

## 四、快速判斷 flowchart

遇到一個詞句不確定：

```
1. 這個詞暗示「治療 / 預防疾病 / 醫療行為」嗎？
   → YES：🔴 Critical（參考第一或第二段禁用表）
   → NO：往下

2. 這個詞有「絕對性」保證嗎？（100%、完全、永久、保證、立即）
   → YES：🔴 Critical（虛偽誇大）
   → NO：往下

3. 這個詞提到「具體疾病名」或「症狀治療」嗎？
   → YES：🔴 Critical
   → NO：往下

4. 這個詞是美白 / 抗老 / 修護類？
   → 檢查是否搭配禁用動詞（消除 / 去除 / 治療）
   → 有搭配：🔴 Critical
   → 單獨使用（如「抗老」）：🟠 High，建議替代

5. 看起來 OK，但有點邊界？
   → 標「建議法務覆核」🟡 Medium
```

## 五、法規更新與爭議處理

- 衛福部食藥署公告會不定期更新。**法規內容最後核對日：2026-04**（此日期僅在重新核對法規時更新，與檔案編修日無關）。距核對日超過 6 個月（即 2026-10 起）未重核，Welson 應重新確認
- 遇到新型態宣稱（例如新成分「外泌體」「幹細胞萃取」的合法表述），參考同類產品上市案例
- 違規案件可在食藥署官網的「裁罰案件公開查詢」找到先例：https://www.fda.gov.tw/TC/siteContent.aspx?sid=2019
