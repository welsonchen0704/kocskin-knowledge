# 違規詞 → 合規替代字典

審查時偵測左欄「違規詞」，改用右欄「建議替代」。替代詞不是唯一答案，可依語境調整，但不要偏離合規方向。

## 🟡 品牌語氣偏離 → 建議調整

| 偏離類型 | 原文示範 | 建議改寫方向 |
| --- | --- | --- |
| 焦慮行銷 | 「再不用就完了」「妳的皮膚已經…」 | 改為正面激勵：「一起養成好膚況」「每天一點點，肌膚會感謝你」 |
| 過度口語 | 「姊妹們快衝」「真的 TM 好用」 | 改為親切但有質感：「推薦給追求品質的妳」「深受好評的選擇」 |
| 過度正式 | 「本公司隆重推出」「誠摯邀請各位消費者」 | 改為有溫度：「KOCSKIN 新品登場」「和妳分享我們的新品」 |
| 誇大神化 | 「神級面膜」「逆天抗老」 | 改為具體描述：「深度保濕面膜」「抗老保養新選擇」 |

## 使用方式

審查文案時：

1. 先用〈compliance-rules.md〉的 flowchart 判斷是否違規
2. 查本檔對應的替代詞
3. 給使用者 **2-3 個替代版本**（不同語境可能適合不同版本）
4. 若本檔沒列到的詞，依〈compliance-rules.md〉的原則類推

## 更新

新增替代詞時，寫入對應分類，加日期。現有法規詞庫以 2026 年標準為準。
