# KOCSKIN 投廣圖 Wireframe 製作規範

本 skill 記錄 Welson 於 2026-08-20 拍板的固定規則。產出前先讀活動表（Google Sheets 年度檔期表）確認當期活動，並依 R1 查 Notion 商品資料庫 V2 合規卡。範圍（做哪些活動線/切角/張數）每次先與 Welson 確認，圖面規則則直接套用本檔。

## 一、圖面文字硬規則（每條都是 Welson 明確裁定，不得自行改回）

1. **價格**：不加 NT；折扣價前一律標「活動價」（例：`活動價 $1,380`）；原價以刪除線另列一行（`原價 $1,960`）。售價紅 #C8102E 只用於價格/折扣/促銷標籤。
2. **品名**：一律用完整正式品名（以 V2 為準），不掛 KOCSKIN／KOC 前綴。例：SC亮白賦活精華乳、3D全能亮白菁萃、亮白保濕化妝水、讓夜好眠全能乳霜、全能亮白活膚面膜、焦糖胜肽修護潤唇膏；保健：葉黃素菁英配方膠囊、挪威頂級rTG魚油軟膠囊、開環型紅麴納豆膠囊、益生守護者益生菌。
3. **主標斷句**：不用逗號，用全形空格（例：「雙十寵愛季　開搶！」「秋日養膚　3D系列開補」）。規格表/文件內文可保留逗號。
4. **副標做減法**：品名已出現在價格行時，副標不重複品名（例：S1 副標只寫「熱銷補貨 2000 瓶到貨」）。促銷機制已在副標時，不再重複一行紅字價格（例：保健任選）。
5. **不上圖**：活動起訖時間（規格表列「檔期（不上圖）」供投放參照；貼文文案/落地頁須標明檔期）；保健「孕婦或服藥者請先諮詢醫師」警語（由貼文文案端處理，發文必帶）。
6. **組合名**：組合以檔期核定名稱為正式名（例：「秋日養膚三件組」），視為品名層級。

## 二、版型與尺寸

- 每張素材出兩個版位：1:1（1080×1080）＋ 9:16（1080×1920）。
- 版型自上而下：品牌識別列（Logo）→ 主標（襯線）→ 副標 → 主視覺區（商品去背/情境）→ 原價刪除線＋活動價（售價紅）→ 贈品帶（淺粉膚底）→ CTA 鈕（玫瑰金）。
- 每張附「素材規格」表：訴求切角／主標／副標／價格優惠／檔期（不上圖）／CTA／小燕版位／設計備註。
- 標籤僅限 CIS 核准集：人氣熱銷・限量・加大版・新品・滿X享Y折（須填實數且與機制相符）・有贈品；任選機制用「任選N件N折」實寫。

## 三、CIS 色彩與字體（v2.0 採樣值）

- 玫瑰金 #CC9782（主色/CTA）、Espresso #4D3E36、暖白 #FFF5EC、淺粉膚 #EAD6CA、標題深玫瑰棕 #3E1C18、售價紅 #C8102E（僅價格）、保健綠 #8FA68E（僅保健線）、墨色 #241613。
- 成品字體：思源宋體（主標）×思源黑體（內文）；**Wireframe PPT 一律用 macOS 內建「Songti TC」＋「PingFang TC」**，避免 Welson 電腦出現亂碼（教訓：Noto CJK 字型名未安裝會整片豆腐字）。
- 商品圖 1:1 去背白底柔和頂光；寧可留白不堆疊。

## 四、小燕（執行長）使用規則

- 僅用於主檔主視覺/品牌質感類素材（品牌人格區）；單品促銷、見證、保健線一律純商品圖（產品決策區不放人物）。
- **小燕出現的整張素材全幅**（不是只有照片旁）不得有任何功效字句，只能有活動名/價格/品牌語——名人＋功效語境＋付費投放會倍數加重裁罰。
- 小燕版 vs 純商品版可做 A/B 測點擊率。稱謂一律「小燕／執行長小燕」。

## 五、合規流程（不可省）

1. 寫任何商品文案前查 V2 合規卡；品名帶「亮白」的 SKU 走 C 案（只寫透亮/亮白一般用語，不寫美白/淡斑）。
2. 優惠機制照活動表據實寫：x2 組合價不得寫「買1送1」；「補貨N瓶」「限量」須為事實並留存憑證；刪除線原價須為實際售價。
3. 見證角只能用真實顧客回饋（不得捏造、不含療效字眼、留存截圖與授權），回填後必須重跑合規審查。
4. 睡眠關聯品（讓夜好眠系列）：品名可出現，不得延伸助眠句，視覺禁床鋪/閉眼/月亮意象。
5. 產出後派 fresh subagent 以 kocskin-compliance-check 四關審查（逐關結論），修正後交 Welson 確認才算定稿。

## 六、產出流程摘要

讀活動表當月區塊 → 與 Welson 確認活動線/切角/張數（AskUserQuestion）→ V2 查合規卡 → 依本規範產 wireframe PPT（pptxgenjs，LAYOUT_WIDE）→ 四關合規審查 → 修正 → 交付並存到 Welson 指定資料夾（本機目錄＋對話檔案卡）。
