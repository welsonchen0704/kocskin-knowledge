# KOCSKIN 直播+1 排品規劃

版本：2026-08-31 規則（多場連續檔期、跳週、避主力檔、官網底線價、情境組、專案標、v0→v1 節奏、新資料夾結構）；2026-09-14 修訂 description 與錯字，規則內容零改動。

## 0. 定位

把「庫存 ＋ 歷史銷售 ＋ 歷史組合 ＋ 官網當檔活動」轉成可執行的排品建議表。
直播+1 是帶娛樂性的銷售節目：排品是骨架，互動機制是節奏。
Skill 負責算數據、找衝突、攤開選項；Welson 負責取向、價格底線、機制挑選、定稿。不得替 Welson 自動決定。

## 1. 輸入（資料夾 `~/Desktop/01_KOCSKIN工作/13_直播+1`，2026-08-31 起結構）

```
00_歷史組合表/   直播+1歷史組合表_YYYY-MM-DD下載.xlsx（Google Sheet「直播+1」為正本）
01_排品建議/     排品建議_YYYY-MM-DD場_vN.xlsx（本 skill 的產出）
02_庫存與叫貨/   庫存表_YYYY-MM-DD.xlsx（sheet BQY_INVENTORY）、叫貨清單_*
03_出貨資料/場次YYYY-MM-DD/  出貨_信用卡.xlsx、出貨_到付.xlsx、出貨_海外.xlsx、補單_*
```

1. **庫存表**：只取「倉別=良品」可用量，同 SKU 多批號加總；全程註明快照日期（R6）。另向 Welson 要「本月入庫時程」，排到入庫日之後的場次才能算入。
2. **歷史組合表**：一場一個 sheet（民國式日期），「XXXXXX排品建議」sheet 是該場最終版。
3. **出貨資料**（sheet 秋雨退庫資料）：每列一個品項明細。
4. **官網當檔活動表**（Google Sheet 年度檔期）：必要——沒有它算不出底線價。
缺任一類 → 明講缺什麼，不得憑記憶補數字。

## 2. 資料判讀的坑

- 信用卡檔「訂單金額」全是 0，只有到付檔有金額；客單價只能用到付樣本估，要註明樣本侷限。
- 出貨檔日期 ≠ 直播日期（用訂單日期推場次，與 Welson 確認）。
- 品名跨場寫法不一，彙整一律用「商品貨號」。零星小檔是補單，併回鄰近場次。
- 人氣指標用「下單筆數」。
- 歷史檔有些場 order-1/2 的信用卡↔到付對調，以欄位內容判斷。

## 3. 系統與品牌硬規則（Welson 2026-08-31 訂）

- **組合內容一律固定**：直播+1 系統不支援「任選幾件」（寫「黑x4＋粉x2」，不寫「黑/粉任選6」）。盲包內容由我方定，不受影響。
- **避開當週主力檔**：官網正在跑或即將開跑的主力檔商品（例：氣墊回饋檔、玫瑰乳液檔）不排進直播；非主力檔（保健回歸、封館加1元多1件等）可排入穿插。
- **底線價**：直播每單位價必須低於官網當月最便宜單位價（含買X送Y、第二件券價、加價購、封館五折換算），否則客人官網買就好。每標備註寫「直播單價 vs 官網最低」。官網是小組合，直播用大組拉低均價即可。
- **情境小組**：除單品多入外，每場 2 組「消費者需求情境組」（每組約 3 品），價格低於官網湊同組。名稱避療效語（用「毛孔油光調理」「膚況舒緩」，不用「痘痘肌專用」「解決方案」）。
- **安瓶火車頭不可連場都出**：連兩場後休一場；安瓶庫存若有專案配額（如配給官網主檔），先扣除再算直播可用量，並跨場累計消耗。
- **價格底線由 Welson 訂**（已知：膠原飲 x3 ≥1,480、凝霜 x3 ≥1,280、乳霜 x3 1,680）；標定價前先查記憶與專案文件裡的底線。
- **專案標**（非常態）：如「李阿姨信任標」——先開價讓粉絲先加 → 倒數兩分鐘 → Welson 宣布個人各再加送。總價值以最終件數計，備註寫加送前後折數；加送內容不預告。
- 小獎對外一律稱「神秘禮物」「星願好禮」，不講品項。V2 列「贈品／加價購」的 SKU 只能當贈品，不當正式標。

## 4. 多場連續檔期（例：週年慶五場）

- 先與 Welson 定「每場主線」（依商品線分幕），再排單場。
- **跳週規則**：品當過正式標後，下一場只能當組合成分或贈品；隔一場回歸時必須換組法或換贈品。每場附「跳週檢查」一行。
- 盲包內容跨場零重複；機制每場輪換；滿額門檻可跳著設。
- **節奏**：每場前一週出骨架 v0（Welson 怕來不及）；上一場出貨檔＋新庫存表到手後重核升 v1（弱銷降役、限量重算、配額實扣）。還未確定到貨的品用「候補標」預排，標明啟用條件。
- 檔期專屬橋段（如週週抽手機）依 Welson 指示固定位置（預設開播約 45 分喚醒點），寫成 ★ 列，標明抽獎池與負責人。

## 5. 分析流程

1. 庫存表 → 良品可用量總表，三色分類（必清高庫存／夠開標／低庫存不能開標）＋未到貨＋贈品池。
2. 最近一至兩場出貨 → 各標下單筆數排行；弱銷（<5 筆）降役。
3. 到付檔 → 客單價分布（中位／P75／P90）供滿額門檻。
4. 官網活動表 → 每 SKU 當月最低單位價（底線價表）＋主力檔避開清單。
5. 歷史組合表 → 牌價（總價值÷件數）、最後出場場次、上一場重複度。
6. 產出草案＋機制 → 跨標庫存衝突核算 → 對話提案（選擇題問拍板事項）→ Welson 確認 → 出 Excel。

## 6. 排品原則

- 固定標保留、微調不換品（但受第 3、4 節跳週與安瓶休場規則約束）；輪替；弱銷轉贈品／盲包／獎品；贈品優先挑待消化庫存；限量由庫存反推並扣其他標占用。
- 高庫存品優先當贈品與盲包成分。

## 7. 互動機制庫（每場挑 2–3 種，輪換）

秒殺限量（開場 0.36–0.40）｜留言/分享抽（開播前）｜信任標凹價｜轉盤紅包 0/88/188/288（機率 40/30/20/10，表上放期望成本公式）｜抽籤定價（三檔全保本，成本基準 15%）｜抽籤加碼｜滿額階梯送（門檻在中位–P75，不累贈）｜盲包壓軸。
主持：威哥／冠婷上鏡，KK／丁丁幕後。戲點標 3–5 個，口播不踩 R3 禁語（亮白線用「透亮、亮白」不用「美白」；保健用「幫助維持消化道機能」句型）。口頭加碼預留庫存。

## 8. 計算慣例

總價值＝正裝價值（同品買X送X計入，跨品贈品不計）；牌價由歷史總價值回推，找不到標「待查」；折數＝建議價÷總價值（Excel 用公式）。

## 9. 產出

1. 對話提案：排品表（含單價 vs 官網欄）＋機制＋庫存衝突＋跳週檢查＋待拍板選擇題。
2. Excel `01_排品建議/排品建議_YYYY-MM-DD場_vN.xlsx`，欄位 A–J：`庫存(快照)｜標數｜時段｜標數（角色，含贈品寫法）｜商品名稱｜建議價格｜折數｜總價值/贈品不算入｜備註｜戲點備註`，★ 橋段列黃底、警示列橙底；表尾依序：互動機制區（含預留庫存）、抽籤/轉盤設定區、庫存衝突核算區、跳週檢查、升 v1 待辦、對外規則。在雲端建檔 → recalc → SendUserFile → device_commit_files 寫回資料夾。
3. 寫檔後 read-back（R7）；把拍板結論寫進專案文件與記憶；Welson 要求時寫 Notion 📚 專案管理（先預覽再寫，寫後讀回）。

## 10. 紅線對接

R5 停售品不得排入（正本＝compliance-check brand-rules ＋V2 SKU狀態）；R6 庫存為快照，開播前一天重拉；本表為內部排品表，情境組名、戲點口播、預告貼文另走 kocskin-post-writer 與 kocskin-compliance-check（R2）。
