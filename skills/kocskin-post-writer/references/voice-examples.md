# KOCSKIN 品牌語氣範例（好 vs 壞對照）

品牌語氣是最難用規則描述、最容易被誤解的部分。這份檔案用**具體對照**讓 AI（或人類撰稿人）對齊標準。

品牌定位：**親切、專業、有溫度，不誇大、不焦慮**
目標客群：**25-45 歲女性，重視成分安全，追求簡單有效保養**

---

## 一、開場 / 第一行

### ✅ 好範例（懂成分的閨蜜）

- 「換季皮膚乾到快脫皮？這是敏感肌 + 換季的雙重壓力。」
- 「『我每天都在塗保濕精華啊，為什麼還是乾？』」
- 「保濕不只是『多塗一點』，而是一個分層工程。」
- 「上週我們拿到最新一批的 SGS 檢驗合格報告。」
- 「35 歲、混合偏乾肌，小雅的 14 天紀錄。」

這些為什麼好：**具體、有對象感、不推銷、讓人想繼續看**

### ❌ 壞範例（太多角度都錯）

- 「姊妹們衝啊！！！這支我真的 TM 無法！」
- 「你的皮膚已經老化中！再不保養就來不及了！」
- 「本公司隆重推出新品，誠摯邀請各位消費者蒞臨選購」
- 「神級面膜來了！逆天抗老不是夢！」
- 「【限量搶購】年度最強！錯過等一年！」

問題在哪：
- 第 1、5 句 → 過度口語、感嘆詞狂用，不像 KOCSKIN 的「有溫度」
- 第 2 句 → 焦慮行銷，違反「不焦慮」原則
- 第 3 句 → 過度正式，像 B2B 公文
- 第 4 句 → 誇大神化，違反「不誇大」原則

---

## 二、商品描述

### ✅ 好範例

> 「B5 保濕修護精華用了 5% 高濃度泛醇（B5），這個濃度能幫肌膚維持水分平衡，搭配專利歐可靈和軟毛松藻，舒緩乾燥不適感。」

為什麼好：具體、有數字、有邏輯連接、不過度形容

### ❌ 壞範例

> 「B5 精華超神！敷完臉就是水嫩水嫩，敏感肌救星，媲美醫美級保濕！」

問題：
- 「超神」→ 主觀空泛
- 「敷完臉就是水嫩水嫩」→ 疊字太多、不具體
- 「敏感肌救星」→ 誇大用詞
- 「媲美醫美級」→ 🔴 醫美類比違規

### 修復版

> 「B5 保濕修護精華裡的 5% 泛醇 + 專利歐可靈，是針對敏感肌換季常見『擦什麼都緊繃』設計的配方，目的是幫肌膚維持水潤彈性，讓後續保養更穩定。」

## 三、轉折 / 痛點描述

### ✅ 好範例（不焦慮但有共鳴）

- 「你是不是也有過：早上起床臉一摸就起屑，妝前保養多塗 2 次還是緊繃？」
- 「換季每次都在擔心會不會爛臉。」
- 「保養品一瓶一瓶買，但總覺得治標不治本。」

為什麼好：有情境、有共鳴、讀者會「被懂到」

### ❌ 壞範例（焦慮 / 恐嚇）

- 「你的皮膚已經老化了！再不保養就晚了！」
- 「現在不處理，5 年後你會後悔！」
- 「別再讓皺紋毀掉你的臉了！」

問題：恐嚇式行銷，違反 KOCSKIN「不焦慮」原則、讀者看完反感而非想行動

---

## 四、CTA 呼籲行動

### ✅ 好範例

- 「你也是換季困擾族嗎？留言告訴我你的保養日常，我們一起找解方 💛」
- 「想深入認識這支精華？留言『B5』我們私訊使用細節給你 💌」
- 「你覺得呢？留言告訴我 ✍️」
- 「想看 SGS 檢驗報告？留言『SGS』我們私訊給你 📄」

為什麼好：給具體互動行為、有溫度、回饋也具體（私訊/資料）

### ❌ 壞範例

- 「馬上購買！」「立刻搶購！」
- 「不買你就虧大了！」
- 「現在下單還送 XX！手腳要快！」

問題：太商業化、失去品牌質感。KOCSKIN 的 CTA 應引導「互動」與「了解」而非「立刻買」

## 五、涉及執行長小燕的敘述

### ✅ 好範例

> 「『我們自己都會塗在臉上，家人也會用。不是合格就好，是每一批都要合格。』— 執行長小燕」

> 「小燕每週會親自試用每一批新品，這是她從創業第一天就堅持的事。」

為什麼好：有故事、有人格、執行長呈現「用心」而非「老闆」

> ⚠️ 上述引用句為**體裁示意**，非小燕真實發言紀錄。實際撰文要引用小燕的話之前，需先向小燕本人確認原話或取得授權，避免虛構名人引述違反品牌紅線。

### ❌ 壞範例

- 「李燕執行長隆重宣佈…」 → 🔴 用本名、太正式
- 「小燕姐親自代言」 → 「姐」過度隨便
- 「李總表示…」 → 🔴 本名、公事化

## 六、涉及商品族群 / 膚質

### ✅ 好範例（具體族群）

- 「特別適合：乾燥肌、敏感肌、醫美術後保養、換季膚況不穩定的你」
- 「辦公室冷氣族、孕媽咪、追求簡約保養的人」
- 「25 歲以上想開始抗老、但預算有限的你」

### ❌ 壞範例（空泛）

- 「適合所有想變美的人！」
- 「無論你什麼膚質都適用！」
- 「大家都超愛這支！」

問題：沒有族群感、讀者無法對號入座

---

## 七、涉及「抗老」「保濕」等敏感詞

### ✅ 合規 + 有品牌溫度

- 「撫平細紋外觀，讓肌膚看起來更緊緻」
- 「深度修護肌膚屏障，幫敏感肌重拾穩定」
- 「延緩肌膚老化感，日常就能堅持的抗老保養」
- 「均勻膚色、提亮暗沈，讓氣色看起來更有光」

### ❌ 違規 + 誇大

- 「消除細紋、淡化皺紋」 → 🔴 醫療宣稱
- 「治療敏感肌、抗過敏」 → 🔴 醫療宣稱
- 「一擦見效抗老、逆轉年齡」 → 🔴 絕對性 + 違規
- 「讓斑點消失不見、重拾瓷白肌」 → 🔴 醫療宣稱

## 八、品牌認證 / 專業訴求

### ✅ 好範例

> 「MIT 台灣製造、無動物實驗、不定期 SGS 檢驗——這些不是廣告詞，是我們做保養品的最低自我要求。」

為什麼好：具體、有自信、不過度吹噓、有價值觀（為什麼做）

### ❌ 壞範例

- 「業界最強、業界第一、業界唯一！」 → 🔴 違反公平交易法
- 「XXX 品牌做不到的，KOCSKIN 做到了」 → 影射他牌
- 「全台灣最好的保養品！」 → 絕對性宣稱

## 九、見證描述

### ✅ 好範例（具體 + 合規）

> ⚠️ 「小雅」為**虛構示意角色**，非真實 KOC。實際撰文要使用真實 KOC 並取得授權。

> 「小雅的 14 天紀錄：
> Day 3｜『不再一洗完臉就要馬上補擦。』
> Day 7｜『妝前保養只要一層。』
> Day 14｜『我以為是刺痛體質，現在發現可能是以前保濕沒做夠。』」

為什麼好：有時間感、有具體描述、用「小雅覺得」「小雅發現」而非「商品消除了 XX」

### ❌ 壞範例（違規 + 空泛）

- 「用了 1 週皺紋消失！」 → 🔴 醫療宣稱 + 絕對時效
- 「敏感肌從此不爛臉！」 → 🔴 治療宣稱
- 「100 人實測 100 人滿意！」 → 🔴 絕對性 + 可能是假數據
- 「瞬間亮白 3 個色號！」 → 🔴 瞬間 + 違反化粧品原則

## 十、Hashtag 風格

### ✅ 好範例

```
#KOCSKIN #克麗詩黛 #B5保濕修護精華 #敏肌修護系列 #換季保養 #敏感肌保養 #保濕精華 #MIT保養品
```

為什麼好：品牌 + 商品 + 主題清晰分層

### ❌ 壞範例

```
#超狂 #不買後悔 #神級 #全台最夯 #本週爆款 #快搶 #限量
```

問題：過度行銷、沒有品牌識別、會讓 KOCSKIN 看起來像雜貨電商

## 十一、Emoji 使用原則

### ✅ 節制有品味

- 🌿 植物 / 天然（保養品牌常用）
- 💧 保濕 / 水潤
- ✨ 閃亮 / 光澤
- 💌 私訊 / 收到
- 📄 📊 專業 / 資料
- 🌸 春季 / 花（季節性活動）

### ❌ 過度 / 失格

- 🤑💸💰（太商業、像業配）
- 😭😫🥺（過度情緒化）
- 🔥🚀💣（過度張揚）
- 一行用 5 個以上 emoji

**原則**：每則貼文 emoji 總數 < 10 個，且不要每行都 emoji

## 十二、當你不確定時的檢查清單

寫完一段後，問自己：

- [ ] 一個 35 歲的 KOCSKIN TA 讀完會覺得「被懂了」嗎？
- [ ] 讀完會覺得「這個品牌懂成分」嗎？
- [ ] 有沒有任何一句讓她感到壓力 / 焦慮？
- [ ] 有沒有任何一句讓她覺得「太浮誇 / 太像詐騙」？
- [ ] 有沒有任何一句違反合規？（再去 `kocskin-compliance-check` 一次）
- [ ] 讀完她知道「下一步做什麼」嗎？

全部 Yes / No 正確 → 可以發。
