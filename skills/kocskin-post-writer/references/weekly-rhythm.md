# 發文節奏與季節建議（背景參考）

> ⚠️ **本檔為背景建議，不是硬性規則。**
> 新版 SKILL.md 主檔已不做跨篇類型比例追蹤，本檔保留作為「什麼時候發、季節主題對位」的背景參考。撰文時不必硬套節奏，遇到突發新品、危機處理、重大檔期都可以彈性。

---

## 一、發文日節奏建議

**每週 4 篇，固定日**：

| 星期 | 類型傾向 | 原因 |
| --- | --- | --- |
| 週一 | 商品價值型 或 教育型 | 週一讀者狀態較認真，適合深度內容開啟一週 |
| 週三 | 見證品牌型 或 教育型 | 週中情緒需要「人味」，故事型貼文效果好 |
| 週五 | 商品價值型（常帶週末活動） 或 促銷導購型 | 週五晚上讀者準備週末，購物意願較強 |
| 週日 | 教育型 或 見證品牌型（輕鬆） | 週日晚上放鬆、內容型更適合 |

**不發文日**：週二、週四、週六（除非有重大活動 / 檔期）

### 為什麼不是每天發？

- **讀者疲勞**：每天發會讓追蹤者滑掉率提高，互動率反而下降
- **演算法**：FB / IG 對 post frequency 過高的粉專會壓觸及
- **產製成本**：內容品質比數量重要，每週 4 篇品質穩定 > 每天一篇品質浮動
- **品牌定位**：「有溫度、有專業」的品牌不需要刷屏

## 二、季節 / 檔期主題建議

### 春季（3-5 月）

- 換季保養主題熱度高 → 教育型多談「換季不穩定膚況」
- 母親節（5 月第二個週日）→ 活動主打高單價禮盒組合
- 5-6 月開始氣溫升高 → 防曬 / 控油主題

### 夏季（6-8 月）

- 防曬 / 美白 / 控油為主打
- 7-8 月高溫期 → 夜間儀式 / 急救修護主題（熱傷肌膚）

### 秋季（9-11 月）

- 換季再次熱門（敏感肌回潮）
- 抗老 / 抗皺主題熱度高
- 雙 11（11/11）→ 全年最大檔期

### 冬季（12-2 月）

- 保濕 / 修護為主打
- 農曆年前 2 週 → 過年送禮主題
- 2 月情人節（14日）→ 浪漫情境（非主力檔期）

---

## 三、通用提醒

1. **促銷型不要連續發**：即使檔期內也建議把「活動告知」打散，搭配價值型內容
2. **見證品牌型最容易被忽略**：但它是建立信任的核心，長期缺席會讓品牌變單薄
3. **教育型不只是保養知識**：成分科普、膚質判別、保養 SOP、迷思破解都可
4. **節奏是節奏，不是鐵律**：突發新品、危機處理、重大節日，彈性優先
