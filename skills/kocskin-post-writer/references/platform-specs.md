# Facebook / Instagram 格式規範

FB 與 IG 雖然都是 Meta 平台，但使用行為、演算法、讀者習慣差很多。同樣的主題要針對平台微調。

> **Threads 不在本檔範圍。** Threads 是獨立內容線，人設（K編）、時段、hashtag、圖片規則完全不同 → `kocskin-threads-writer`。

---

## 一、字數

Welson 2026-07-25 裁定，取代舊的「FB/IG 一律 150 字內」合併規格：

| 平台 | 規格 | 備註 |
| --- | --- | --- |
| Facebook | **不設字數上限**，依內容需要決定長短（2026-08-02 Welson 確認，正本＝《發文渠道分流規範》〈二〉） | 前 3 行決定是否展開 |
| Instagram | **150 字內** | 讀者多半看第一行就決定滑掉與否 |

**FB 目標區間（Welson 2026-08-07 補充，非上限）：**

| 情境 | 建議字數 |
| --- | --- |
| 小燕第一人稱（配圖有她入鏡） | **400–700 字** |
| 品牌口吻商品文 | 250–400 字 |

第一人稱寫短會失敗——人味需要篇幅才長得出來，200 字只夠講完賣點。詳見 [ceo-first-person.md](ceo-first-person.md)。

## 二、版面設計

### Facebook

- **前 3 行是關鍵**（會在動態消息直接顯示，之後要點「顯示更多」）
- 可使用 emoji 開頭（🌿 💧 ✨ 📱）但不要每行都 emoji，會顯廉價
- 斷行用得大方，但不要每句都斷行（會像 IG 排版）
- 連結可以直接放在正文中（FB 會處理成預覽卡）
- ⚠️ 但若 Notion「導購連結」欄已填，**正文就不要再放同一條**（引擎 v2 會在文末自動接一次，會重複）
- Hashtag **3–5 個**放在文末，不要超過 7 個（會被演算法視為 spam）
- 表情符號可以用，但專業品牌建議少於 8 個

### Instagram

- **第一行是命脈**（決定是否滑掉），通常是標題／問題／痛點
- 主文要**大量斷行**（每句一行或每兩句一行，留白多）
- emoji 使用更自由（但與品牌氣質要一致）
- 連結只能放 Bio，正文寫 `連結在 Bio 📍` 或 `Link in bio 👆`
- Hashtag **3–5 個**（含 #KOCSKIN），見下方
- 限時動態（Stories）不在本 skill 主流程，另行處理

### 斷行範例對照

**FB 版本**（較緊湊，可展開細節）：

```
換季皮膚乾到快脫皮？這是敏感肌 + 換季的雙重壓力。
KOCSKIN B5 保濕修護精華這樣幫你：
✦ 5% 高濃度 B5（泛醇）- 幫肌膚維持水分平衡
✦ 專利歐可靈 + 軟毛松藻 - 舒緩乾燥
```

**IG 版本**（較大方，150 字內）：

```
換季皮膚乾到快脫皮？
.
.
這是敏感肌 + 換季的雙重壓力。
```

## 三、Hashtag 策略

品牌規格：**FB／IG 皆 3–5 個，含 #KOCSKIN。**

### Facebook

1. **品牌**：#KOCSKIN #克麗詩黛
2. **商品／系列**：#B5保濕修護精華 或 #敏肌修護系列
3. **主題（選 1–2 個）**：#敏感肌保養 #換季保養

❌ 不要用 FB 做 hashtag 海戰術（> 7 個會被演算法壓）

### Instagram

同樣 3–5 個，優先序：品牌 1–2 個 → 商品／系列 1 個 → 主題 1–2 個。

- 放在正文下面、留 3–5 行空白，讓 hashtag 不搶正文視覺
- 中英文混搭 OK，但優先中文（KOCSKIN 主戰場台灣）

> 📌 **待決事項**：業界慣例 IG 常用 15–30 個分層 hashtag 擴大觸及，做法是把長尾 tag 放**第一則留言**、正文只留 3–5 個。目前品牌規格未開放此作法。若要試，先問 Welson，不要自行加碼。

## 四、Call to Action（CTA）差異

### Facebook

- 「想深入了解？留言『+1』我們私訊使用細節給你 💌」
- 「👇 點留言看更多客戶反饋」
- 「官網連結在下方 👇 / 點此進官網：[連結]」
- 「留言告訴我你的膚況困擾，我們一起找解方」

### Instagram

- 「連結在 Bio 📍」「Link in bio 👆」
- 「想看成分拆解？雙擊愛心 ❤️ 我下一篇開講」
- 「你覺得呢？留言告訴我 ✍️」
- 「限時動態有試用影片 👉 快去看」

（詳細節奏見 [weekly-rhythm.md](weekly-rhythm.md)，這裡是平台最佳時段）

### Facebook 最佳時段（台灣 TA）

- **週一至週五**：晚上 20:00–22:00（下班後、睡前）
- **週日**：下午 14:00–16:00、晚上 20:00–22:00

### Instagram 最佳時段

- **週一至週五**：中午 12:00–13:00、晚上 20:00–21:00
- **週日**：早上 10:00–11:00、晚上 20:00–22:00

## 六、要避免的常見錯誤

1. **一貼兩用沒調整** — 把 FB 長文直接貼到 IG，讀者滑掉率爆高
2. **搬去 Threads** — FB/IG 文案搬到 Threads 是明文禁止（兩條獨立內容線）
3. **IG 用連結** — IG 正文沒連結功能，寫了也沒用
4. **FB 猛放 hashtag** — 超過 7 個會被降觸及
5. **文長無重點** — 無論 FB／IG，第一行都要抓住讀者
6. **CTA 模糊** — 「歡迎了解」「有興趣可以來問」，沒告訴讀者**做什麼**
7. **商品照配錯文** — 圖文不符會破壞專業感（圖是安瓶、文說精華）
8. **錯誤綁活動 hashtag** — 檔期結束了還用 #春季修護組，會被消費者認為品牌混亂
9. **連結重複** — Notion「導購連結」欄與 FB 正文各放一條同樣的連結

## 七、當要求 FB + IG 兩版時

**不要**：寫一版兩邊用。

**要**：

- 寫一份主文大綱（核心訊息、賣點、CTA 方向）
- **FB 版**：展開為段落式，完整說明，長度依內容需要
- **IG 版**：改寫為 150 字內短句式，大方斷行，視覺留白多
- Hashtag 各自套用（皆 3–5 個含 #KOCSKIN，但選字可不同）
- 第一行**兩個都要重新寫**：
  - FB → 有故事感、痛點共鳴
  - IG → 視覺 hook（問題／痛點）

**職責分工**：

- FB 管「完整資訊、社群累積」
- IG 管「視覺美感、品牌形象」
- （Threads 管「對話、人格、即時反應」——但由另一支 skill 負責）
