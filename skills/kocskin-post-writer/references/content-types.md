# 4 種內容類型 — 結構範本與範例

KOCSKIN 社群貼文的內容類型分為四類。**每篇單獨選一類**，依主題、商品、檔期決定，不做整體比例追蹤。

- **商品價值型**：推單一商品的賣點、成分、適用族群
- **教育型**：保養知識、使用教學、膚質判別、誤解破解
- **見證品牌型**：使用者見證、品牌故事、幕後、人物
- **促銷導購型**：檔期活動、折扣、新品發表

選擇邏輯見本檔末尾〈五、類型綜合判斷 flowchart〉。

---

## 一、商品價值型

### 目標
讓讀者了解「為什麼這支商品值得買」，著重成分、適用族群、具體效益。

### 結構範本

```
[標題 / 第一行 hook：點出一個痛點或好奇]
│
[引起共鳴：2-3 行情境描述，讓 TA 覺得「這是在講我」]
│
[核心賣點：3-5 個，用明確句子配合成分 / 數據]
│
[適用族群：誰會特別受益]
│
[使用方式 / 搭配建議]
│
[CTA：看更多、私訊詢問、留言 +1 索取資訊]
```

### 範例（基於 B5 保濕修護精華）

> 【換季肌膚乾到快脫皮？B5 保濕修護精華這樣救】
>
> 早上起床臉一摸就起屑、妝前保養都要多塗 2 次還覺得緊繃——這不是只有你，這是敏感肌 + 換季的雙重壓力。
>
> 👉 KOCSKIN B5 保濕修護精華怎麼幫你？
>
> ✦ 5% 高濃度維他命 B5（泛醇）— 幫肌膚維持水分平衡
> ✦ 專利成分歐可靈 + 軟毛松藻 — 舒緩乾燥不適感
> ✦ 有機玻尿酸 — 長效補水，不黏膩
> ✦ 無香料、無酒精、無動物實驗 — 敏感肌可安心使用
>
> 👥 特別適合：乾燥肌、敏感肌、醫美術後保養、換季膚況不穩定的你
>
> 💡 使用順序：化妝水 → 精華（就是它）→ 乳液 → 面霜
>
> 想深度認識這支精華？留言「B5」我們私訊使用細節給你 💌

### 重點提醒

- **一定要具體**：成分名稱、濃度（如果 DB 有）、適用膚質 — 都從 `kocskin-product-lookup` 取
- **避免**：抽象形容詞堆砌（「超好用」「敷完肌膚像重生」）
- **合規**：複查禁用詞（消除、治療、抗發炎、修復傷口）

## 二、教育型

### 目標
提供保養知識價值，建立 KOCSKIN 作為「懂保養」的品牌形象。商品可以帶到但不是主角。

### 結構範本

```
[標題：一個問題 / 誤解 / 知識點]
│
[破題：為什麼這個話題重要、常見誤解是什麼]
│
[知識點 1 — 具體說明]
[知識點 2 — 具體說明]
[知識點 3 — 具體說明]
│
[實用建議：讀者看完可以做什麼]
│
[軟性連結商品（選配）：KOCSKIN 裡有哪支產品符合這個概念]
│
[CTA：追蹤我們學更多、留言告訴我你踩過哪個雷]
```

### 範例（保濕主題）

> 【保濕不是只有塗保濕精華｜肌膚喝水的 3 個階段】
>
> 「我每天都在塗保濕精華啊，為什麼還是乾？」
>
> 保濕不只是「多塗一點」，而是一個分層工程。今天拆給你看：
>
> 1️⃣ 打開吸收通道｜化妝水 / 機能水
> 清潔後肌膚表面 pH 值需要回穩，這時候一瓶溫和的機能水可以幫後續保養「打開吸收管道」。
>
> 2️⃣ 注入水分本體｜保濕精華
> 玻尿酸、維他命 B5、神經醯胺這類「水分載體」登場，把水帶進角質層。
>
> 3️⃣ 鎖住水分｜乳液 / 面霜
> 這步常被跳過，但少了它，前面兩步的水分 2 小時就會蒸發。
>
> 💡 實用小提醒：乾性 / 敏感肌建議三步都做，油性肌可以只做 1+3 或 1+2。
>
> 你屬於哪種膚質？留言告訴我，我給你推薦適合的組合。

### 重點提醒

- 知識點要**有憑有據**，不要寫得像抄網路養生文
- 可輕量置入 KOCSKIN 商品，但佔比不超過 20% 版面
- 教育型**宣稱面比商品價值型寬**（因為不是直接宣稱商品功效），但仍須過合規——醫療誤導、絕對性宣稱、化粧品禁用詞依然不能用
- 長度可以比商品價值型更長（讀者進來就是想學東西）

## 三、見證品牌型

### 目標
用「真實人」建立品牌信任感。兩個切入：消費者見證、品牌幕後。

### 3A. 消費者見證結構

```
[標題：引用見證中最有感的一句話]
│
[背景介紹：這位消費者的膚況 / 困擾 / 她的身份]
│
[使用過程：幾天、搭配了什麼、遇到什麼轉折]
│
[具體改變（合規！）：不說「消除了 XX」，說「看起來…」「她覺得…」「她不再每天擔心…」]
│
[品牌方的註腳：為什麼我們做這支商品 / 謝謝她分享]
│
[CTA：也有類似困擾？留言告訴我]
```

### 範例

> ⚠️ 以下「小雅」為**虛構示意角色**，非真實 KOC。實際撰文要使用真實 KOC 並取得本人授權，避免見證造假違反公平交易法及品牌信任。

> 【「化妝水上完臉不再繃到想尖叫」｜小雅的 14 天 B5 紀錄】
>
> 小雅是我們其中一位長期合作的素人 KOC，35 歲、混合偏乾肌，換季最怕——臉頰會紅、起屑、擦什麼都覺得黏膩刺刺的。
>
> 「我以前換季都靠不斷補擦，但總覺得治標不治本。」
>
> 小雅試用 KOCSKIN B5 保濕修護精華 14 天後告訴我們：
>
> 📅 Day 3｜「不再一洗完臉就要馬上補擦，乾的感覺慢了一些。」
> 📅 Day 7｜「妝前保養只要一層，化妝水上完臉不再繃到想尖叫。」
> 📅 Day 14｜「原本以為是刺痛感體質，現在發現可能是以前保濕沒做夠。」
>
> 我們做 B5 系列的初心，就是希望敏感肌的朋友不用每天擔心「今天會不會又爛臉」。
>
> 你也是換季困擾族嗎？留言告訴我你的保養日常，我們一起找解方 💛

### 3B. 品牌幕後結構

```
[標題：一個具體故事點 / 數字 / 決定]
│
[為什麼這件事值得分享：連結到品牌價值]
│
[過程 / 幕後：具體情節，有人名、有時間、有掙扎]
│
[得到什麼 / 學到什麼：回扣品牌初心]
│
[CTA：如果你也相信 XX 價值，跟我們一起…]
```

### 範例

> 【SGS 檢驗報告來了｜為什麼小燕堅持 SGS 送檢】
>
> 上週我們的 3D 全能亮白菁萃 拿到最新一批的 SGS 重金屬檢驗合格報告。
>
> 對很多品牌來說，這是一次性文件；對 KOCSKIN 來說，這是不定期的例行公事。
>
> 「我們自己都會塗在臉上，家人也會用。不是合格就好，是每一批都要合格。」— 執行長小燕
>
> MIT 台灣製、無動物實驗、不定期 SGS、不添加香料色素——這些不是廣告詞，是我們做保養品的最低自我要求。
>
> 想看檢驗報告？留言「SGS」我們私訊給你 📄

### 重點提醒

- 消費者見證要**真的**（有真人或取得授權）
- 具體改變**不要涉及醫療詞**（「消除」「治療」等）
- 品牌幕後可以帶執行長小燕（用「小燕」不用「李燕」）
- 合規審查要**特別看見證的改變描述**

## 四、促銷導購型

### 目標
驅動購買決策。這是最短、最直接的類型，但也最容易違規 / 被讀者跳過。

### 結構範本

```
[標題：活動名稱 + 最有吸引力的 offer]
│
[活動 3 要素：什麼、什麼時候、怎麼買]
│
[商品組合 / 推薦（選 1-2 支不要多）]
│
[緊迫感（合規前提下）：限時 X 天、先到先得、限量 X 組]
│
[CTA：明確連結、LINE、私訊流程]
```

### 範例

> 【🌸 KOCSKIN 春季換季修護組｜敏感肌安心入手的時機】
>
> 換季皮膚又開始鬧情緒？3 件組合價給想穩定膚況的你。
>
> 🎁 組合內容：
> ・B5 保濕修護精華（590）
> ・B5 保濕修護面膜 5 入（490）
> ・奇肌超導機能水（690）
>
> 原價 1,770｜組合價 1,490（省 280）
>
> ⏰ 活動時間｜4/22（二）～ 5/5（日）
> 💳 結帳輸入折扣碼｜KOCSPRING
>
> 官網連結在 Bio 📍
>
> #KOCSKIN春季修護組 #敏感肌保養

### 重點提醒

- **不得**用「100% 有效」「立即見效」「保證」這類絕對性用詞（🔴 Critical）
- 緊迫感要真（若是永久價格，不要寫「限時」）
- **避免連續密集發促銷型**（讀者審美疲勞、演算法觸及壓低；同一檔期建議只發 1 篇主推 + 1 篇收尾提醒，不要每天提醒）
- 一定要明確「怎麼買」— 不要只寫「我們有活動」沒連結

## 五、類型綜合判斷 flowchart

使用者丟需求後，用這個判斷應選哪類：

```
1. 使用者明確指定類型？
   → YES：用指定類型，跳到 Step 2 內容發想
   → NO：繼續

2. 主題是具體商品？
   → YES：預設「商品價值型」
   → NO：繼續

3. 主題是保養知識 / 膚質概念 / 成分科普？
   → YES：預設「教育型」
   → NO：繼續

4. 主題是使用者故事 / 小燕 / 品牌決策 / SGS?
   → YES：預設「見證品牌型」
   → NO：繼續

5. 主題是折扣 / 組合 / 檔期?
   → YES：預設「促銷導購型」（注意避免連續密集發）

6. 都不符合？
   → 反問使用者要哪個方向，並給建議
```

## 六、跨類型共同原則

不管哪類，都要守：

1. **先 query 商品資料**（若有提到特定商品）
2. **KOCSKIN 語氣**（親切、專業、有溫度，不誇大、不焦慮）
3. **繁體中文**，不混簡體
4. **合規審查**（文案產完自動跑）
5. **CTA 明確**（至少一個互動 / 轉換機會）
6. **Hashtag 策略**：FB／IG 皆 3–5 個、含 #KOCSKIN（正本＝[platform-specs.md](platform-specs.md)〈三、Hashtag 策略〉；IG 15–30 分層屬待決事項，未經 Welson 開放不得使用）
